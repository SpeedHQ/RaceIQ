How should the settings be grouped into tabs?

The form has 11 setting sections + basic info. Pick the tab structure that feels right.

A

2 tabs — Info + Settings

Keep it simple. Tab 1: name/car/category/description. Tab 2: all tune settings (no more accordion, just always-visible fields laid out in a grid).

Tabs: Info  |  Settings
B

4 tabs — grouped by system

Each tab is a logical system group. Info is always shown at the top (not a tab), then tabs for each group below.

Tabs: Suspension  |  Alignment  |  Drivetrain  |  Aero & Brakes
Suspension = Springs, Damping, ARBs, Roll Center, Anti-Geometry
Alignment = Camber, Toe, Caster
Drivetrain = Gearing, Differential
Aero & Brakes = Tires, Aero, Brakes
C

5 tabs — one per major system

More granular. Each tab maps to a discrete physical system. Info metadata lives in a sticky header above the tabs.

Tabs: Info  |  Chassis  |  Alignment  |  Drivetrain  |  Aero
Chassis = Springs, Damping, ARBs, Roll Center, Anti-Geometry
Alignment = Camber, Toe, Caster, Tires
Drivetrain = Gearing, Differential, Brakes
Aero = Downforce front/rear
