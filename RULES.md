# AI-Assisted Development

AI tools are encouraged for building, reviewing, testing, and maintaining RaceIQ. Use them to support your work, not
replace your judgment.

The person submitting code is responsible for it, whether they wrote it manually, generated it with AI, or used a
combination of both. Before submitting AI-generated changes:

- Review the changes and make sure they are correct, understandable, and relevant.
- Verify that they follow the repository’s existing patterns and requirements.
- Run appropriate checks and tests; do not assume generated code is valid because it looks plausible.
- Check for unintended changes, regressions, security issues, and effects on existing behavior.
- Be prepared to explain and maintain the code.

Do not submit code you have not reviewed, tested or cannot take responsibility for. AI-generated code must meet the same
standards as any other contribution.
