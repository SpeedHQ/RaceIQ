Root cause: Rust's cached car-telemetry vector omitted the four inner-temperature properties from F1 projection; it decoded engine temperature as f32 although Bun uses u16, and cache didn't include trailing suggestedGear byte. Additionally Rust read byte-typed engine/suggested values directly from the *current* frame during snapshot projection, which could be a different packet type than telemetry. Unused best-sector properties were incorrectly projected.

Correction in `native/recorder/src/games/f1.rs`: re-decode engine temperature as u16 into telemetry cache at telemetry packet ingestion, cache trailing signed suggested-gear byte (or zero when absent), project four inner temperatures and suggested gear from that cache, and remove noncanonical `bestS1/bestS2/bestS3` fields.
