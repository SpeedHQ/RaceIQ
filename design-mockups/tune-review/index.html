Tune Review Dashboard — 5 redesign mockups

RaceIQ color scheme · synthetic stint data

0 — Overview

Default landing: all-laps view with lap select dropdown. Stat tiles, track map with issue dots, lap pace strip, per-tire vertical bars (min→max + avg tick, kept from app), stacked input lanes — all laps overlaid faint with mean line, or single lap solid.

1 — Stint Ribbon

Stat tiles + lap pace strip + stacked input lanes (throttle / brake / steering / speed) over track fraction with best-lap ghost and corner markers. Closest to your ask.

2 — Command Center

Consistency gauge + verdict card + smoothness meters left; lap-time regression, sector×lap heatmap, tire temp trends right.

3 — Overlay Analyst

Single shared track-fraction axis: speed overlay (focus vs best), running time delta, input traces. Crosshair across all panels.

4 — Corner Ledger

Corner-by-corner table: min speed, Δ best, brake-point variance, input sparklines, verdict pills. Time-loss waterfall sidebar.

5 — Degradation View

Stint over time: pace with ±1σ consistency band, fuel-corrected pace, degradation fit + projection, tire temp spread, input drift.

6 — Track Focus

Track map left with hover cursor + clickable corners; tabbed right pane: Consistency (steering/brake/throttle compared), Speed & Delta, Sectors, Tires. Cursor synced both ways.

Info missing from current dashboard (added in these designs)

  • Consistency score — 100 − scaled CoV of valid lap times, with σ shown
  • Pace degradation slope — linear fit s/lap + projected future lap time
  • Input traces over track fraction — stacked throttle/brake/steering lines vs best-lap ghost
  • Running time delta — where in the lap time is gained/lost
  • Input smoothness — brake/throttle overlap %, coasting %, steering harshness
  • Brake-point variance per corner — biggest consistency driver
  • Sector × lap heatmap — spot which sector degrades first
  • Fuel-corrected pace — separates tire deg from fuel burn
  • Tire temp spread (FR−RL) — setup-balance signal across the stint
