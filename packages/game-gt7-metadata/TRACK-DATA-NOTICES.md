# GT7 track data notices

`src/tracks.json` and `src/track-signatures.json` derive from
[gt7-datalogger-track-data](https://github.com/jbhoorasingh/gt7-datalogger-track-data).
Track metadata and surveyed data are dedicated under CC0 1.0. Track signatures
also include geometry derived from `zetetos/gt-telemetry` circuit captures,
licensed under MIT, Copyright (c) 2024 vwhitteron.

The data source and captured signature revision are recorded in each JSON file.

`src/cars.json` contains GT7 car IDs and display names derived from
[gt7-datalogger](https://github.com/dedeco-carrera/gt7-datalogger/blob/main/backend/app/data/cars.json),
which is MIT licensed. Copyright (c) 2026 Jermaine Bhoorasingh. Its source data
was generated 2026-08-30.
