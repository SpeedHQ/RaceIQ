# Dashboard widget borders

Standalone dashboard widgets need consistent boundaries without competing with telemetry. Use 1px neutral `app-border` outlines, matching the existing design contract. Clean laps and Consistency are independent widgets, each with its own surface, padding, and outline; this makes their distinct metrics independently scannable. Retain current surfaces and avoid extra borders around nested metrics. Existing game and session card outlines remain unchanged.
