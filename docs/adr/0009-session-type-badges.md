# Session type badges

Use one shared colour-coded single-letter badge for session-type values. The first uppercase letter keeps the user's compact representation consistent across views; full formatted labels in title and aria-label retain distinctions such as Practice 1 and Practice 2. Unknown or unavailable values use U. Reuse existing Badge variants: practice/test day cyan, qualifying/shootout amber, race/sprint green, other known types cyan, unknown neutral. Colour is redundant with letters and accessible labels, never the only signal. Stored session types and sorting remain unchanged.

Dashboard Session time is an explicit exception: plain full labels and a doughnut chart matching Track time distribution communicate proportions and elapsed duration without badges. Keep existing timing totals, Other share and coverage disclosures.
