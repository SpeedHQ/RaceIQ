# Recording frequency backend implementation

Follow [shared contract](recording-frequency-contract.md) and [approved detailed plan](recording-frequency.md), steps0–3/5–8/10 and Verification. Backend owns server/packages/apps-backend; integration coordinator owns shared contracts and final real integration verification. UI and backend proceed independently against the agreed contract.

## Tasks and acceptance
- B1/C1: shared numeric settings contract/defaults, persist before runtime setter, allocation-free phase-preserving native admission; retain fresh acquisition, explicit unstarted pollOnce, FIFO drain, UDP parity and source ceilings.
- B2/C2: complete merged retention validation before side effects, safe externally edited conflict recovery; append nullable cap migration without changing prior migrations.
- B3/C4: server-owned path grouping/reference/favorite/age checks call recording-package strict streaming preflight through the shared contract boundary. Previews are read-only; missing/malformed/unsupported/unreliable groups remain unchanged. Preflight estimates each stream's average rate from its first1,000 samples or whole shorter stream, using persisted timestamps or approved game-clock fallback; round to nearest Hz before applying the 3Hz tolerance. Skip streams with insufficient/invalid spans and files whose streams are within tolerance.
- B4/C4/C5: `packages/capture-formats/src/session/downsample.ts` owns bounded two-pass rewriting preserving all-frame lap windows, endpoints/context/ancillary records, historical clocks and nested iRacing chains. Backend supplies strict record and fresh parser factories without reversing package dependencies. Backend validates/fsyncs sibling output before atomic reference/index-checked publication and cache invalidation. No-removal cap-only update; not-smaller retains source; postcommit unlink failure never reverts authoritative target.
- B5/C3/C5/C6: shared Effect runtime, Ref admission/status and Deferred acknowledgement; storage reservation/finalizers, shared maintenance lock and protected non-cancellable I/O. Ordered compression/downsample/delete, strict ages, immediate completion-spaced schedule, awaited idempotent shutdown. HTTP routes only Promise facades.
- B6: contributor docs, maintenance invariants and bounded approved agent guidance accurately describe installed versions and interruption limits.

## End-to-end verification
Run approved package-suite isolation. Native fixture-backed real loops/recorders over10seconds prove counts, identities, timestamps and actual smaller bytes; actual UDP socket sequence proves50/100 parity (B1). Real settings API/file tests cover defaults, all enum values, failed saves, merged conflicts, no socket/runtime side effects (B1/B2). Real canonical six-game plain/gzip recordings through production API and semantic-telemetry GET verify samples/endpoints/indexes/cache invalidation; cover rollover/reset, F1 ancillary streams, nested iRacing dropped-frame mutation, overlapping windows and caps (B3/B4). Inject write/validation/DB/stale-reference/favorite/active-capture failures; source remains authoritative before commit, target after commit; narrowly named temp cleanup only (B4). Invoke actual maintenance on exact/just-beyond ages and40/100-day recordings; downsample failure skips deletion. TestClock/Deferred tests plus backend SIGTERM/restart smoke prove admission, no overlap/backlog, server-owned jobs and protected I/O finalizers (B5). Final browser checks share contract C1–C6 with UI plan. Run diagnostics failure probe/recovery, package suites, native typecheck, i18n keys and production build. Record evidence and platform limitations; Windows-native games/CPU remain unverified on macOS.
