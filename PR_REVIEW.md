# PR #307 Review: CrewChief-Style State Flow

## Blocking findings

- `server/live-strategy/live-engineer-voice-engine.ts:L100-L127`: **P0 bug:** opponent pace exits early for every game. Generated catalog lacks required semantics: F1 seven, ACC/AC Evo `identity.player-car-class-id`, iRacing `race.pit-status`, FM thirteen. Normalize per-game inputs and add catalog → projector → engine tests.
- `shared/telemetry/live/semantics.ts:L30`: **P0 bug:** ACC spotter requests `race.competitor.position-*`/`speed`, but ACC maps `motion.competitor.*`; `processACCSpotter()` therefore never receives positions. Use canonical motion IDs consistently.
- `server/games/f1-2025/f1-state.ts:L223`: **P0 bug:** opponent `posX` remains raw while player `PositionX` is negated at L468; spotter compares different coordinate systems, producing false or missed overlaps. Apply identical transform to grid coordinates.
- `server/live-strategy/spotter-tracker.ts:L33`: **P0 bug:** `reset()` preserves `lastOverlapMs` and `lastStillThereMs`. New session starting at time 0 suppresses calls until previous session time is reached. Reset complete `SideState`. Reproduced: old session at 100000 emits; new session at 0 emits nothing.
- `server/live-strategy/live-engineer-voice-engine.ts:L72,L135-L139`: **P0 bug:** `playerLapInvalid` is never set. Invalid completed laps still generate pace calls; callout also labels previous lap time with new lap number. Track invalidity during lap and use completed lap number. Reproduced invalid lap emitting `playerLapNumber: 2`.
- `scripts/catalog/extension-metadata.ts:L196-L200`: **P0 bug:** F1 `currentLapInvalid → current-lap-valid` declares normalization, but runtime conversion executor has no implementation for it; resolver returns `unsupported-normalized-executor`. Add executable derivation.
- `server/runtime/native-sources.ts:L32`: **P0 bug:** ACC registration datagram sends once at RaceIQ startup. If ACC launches afterward, packet is lost and broadcast competitor data never starts. Register when ACC process appears and retry/reconnect.
- `server/live-strategy/live-engineer-voice-engine.ts:L223-L240`: **P1 bug:** ACC path neither suppresses player pit state nor filters disconnected competitors, unlike `ACCSpotter.trigger`. Add player pit/formation checks and connected-state filtering.
- `client/src/hooks/useWebSocket.ts:L175-L180`: **P1 bug:** outbound delivery/request messages are removed even when socket is closed. Preserve queue until `OPEN`, then flush on reconnect.
- `client/src/stores/live-engineer.ts:L9`: **P1 bug:** spotter preemption drops current/queued engineer lines without `preempted`/`superseded` delivery statuses. Playback accounting becomes incorrect.

## Duplication and pattern violations

- `server/live-strategy/live-engineer-semantic-input.ts:L25-L33`: duplicates `PACE_REQUIRED`, already diverges, checks wrong iRacing `track-surface-material`, and returns diagnostics ignored by voice engine. Make this the single availability boundary or delete it.
- `server/live-strategy/opponent-pace-producer.ts:L32-L114`: unused second opponent-pace implementation; both exports have declaration-only references. Remove it and associated legacy `shared/racing/live/callouts.ts` contract.
- `server/runtime/config/settings.ts:L57-L62`: six persisted pace settings have zero consumers; runtime hardcodes equivalent defaults. Wire settings into tracker/runtime or remove dead knobs.
- `scripts/catalog/crewchief-callout-coverage.ts:L80-L95`: all evidence hardcodes `event = "Position"`, so Fuel, Damage, Strategy, and other events cite the wrong CrewChief symbol. Model event-specific evidence.
- `shared/telemetry/live/crewchief-callout-contract.ts:L102-L106`: declares 24 CrewChief events, but `engineer-contracts.ts:L17-L21` implements only `spotter` and `opponent-pace`. Current “coverage” means telemetry availability, not functional callout parity. Rename matrix or add actual producers.
- `test/live-strategy/live-engineer-voice-engine.test.ts:L12-L27`: fabricated semantic frames bypass catalog/projector, hiding every per-game availability failure above. Build test frames through real resolvers.
- `scripts/live-engineer/__pycache__/generate.cpython-311.pyc` and `generate.cpython-314.pyc`: tracked generated bytecode despite new ignore rule. Remove from PR.
- `client/public/audio/live-engineer/qwen-v1/full__*.wav`: 1.23 MB used only by developer preview while runtime consumes clips. Move outside production public assets unless intentional.
